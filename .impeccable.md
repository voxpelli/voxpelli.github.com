## Design Context

### Users
Developers, IndieWeb practitioners, and people interested in web standards who visit a personal blog. They arrive via RSS feeds, search, or social links to read articles about Node.js, open source, IndieWeb, and Swedish tech culture. Context is focused reading — they want clear content, fast loading, and well-structured pages.

### Brand Personality
**Thoughtful, Technical, Warm.** A senior developer who cares deeply about web standards, open source stewardship, and building things properly — but communicates with Nordic approachability rather than cold precision.

### Aesthetic Direction
**"Sovereign Warmth"** is the current theme and a good foundation, open to evolution:
- **Palette**: Warm parchment canvas (`#f4f1eb`), deep ink (`#2c2a28`), falu red accent (`#8c2121`), cloudberry orange for secondary emphasis (`#d97714`), stone for borders/muted elements
- **Typography**: Three-font stack — Newsreader (serif) for headings and article body, Public Sans (sans) for UI text, JetBrains Mono for metadata/nav/code. Fluid type with `clamp()`
- **Layout**: Two-column sidebar (340px sticky) + content area on desktop, stacked mobile. Grid paper background texture. Heavy 2px borders for structural elements, 1px for decorative
- **Interactions**: Spring easing on buttons (`box-shadow` depth), post cards with left-border accent on hover, subtle `translateX` on nav hover
- **Dark mode**: Full support via CSS custom properties + `<theme-toggle>` web component
- **Progressive enhancement**: Web components (`<theme-toggle>`, `<relative-time>`) work without JS. `no-js` class on html enables CSS fallbacks

### Design Principles

1. **Content sovereignty** — The content is the product. Design serves readability and structure, never competes with it. Article text gets serif font and 65ch max-width for optimal reading.

2. **Warm technical** — Combine engineering precision (mono metadata, grid background, structured borders) with warmth (parchment tones, serif typography, organic color names). Never cold or clinical.

3. **IndieWeb native** — Microformats (h-card, h-entry, h-feed) are structural, not decorative. Webmentions, feeds, and micropub are first-class citizens. The markup is the API.

4. **Progressive layers** — Works without JavaScript. Works without custom fonts. Works in dark mode. Each enhancement layer adds value without breaking the one below it.

5. **Restrained motion** — Interactions use subtle transforms and opacity transitions (`ease-spring`, `ease-out`). No animation for animation's sake. Respect `prefers-reduced-motion`.
