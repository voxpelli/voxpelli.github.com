Colophon

This site is built with DomStack, a static site generator built on esbuild with convention-based file routing. Templates use async-htm-to-string for JSX-like HTML generation with automatic escaping — types checked by JSDoc and tsc, no build step for templates.

Comments are powered by Webmentions. Content is syndicated via Atom feeds. The site works offline through a service worker and is hosted on GitHub Pages.

Design

The design theme is Sovereign Warmth — warm parchment tones inspired by Scandinavian craft, falu red accents from the traditional Swedish pigment, and a three-font typographic system: Newsreader for reading, Public Sans for interface, and JetBrains Mono for code and metadata. Fonts served by Bunny Fonts (privacy-friendly, GDPR-compliant).

Light and dark modes adapt via CSS custom properties. The three-button theme toggle uses a Shadow DOM web component with aria-pressed states. The layout respects prefers-reduced-motion and prefers-color-scheme.

Source

The full source is on GitHub. Built with ESM, neostandard linting via @voxpelli/eslint-config, and 95%+ type coverage enforced by type-coverage.
